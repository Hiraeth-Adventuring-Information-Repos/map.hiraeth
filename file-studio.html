Your map files

Open a map → edit → Download changes.

Edits stay in your browser. Download changes saves a JSON copy to your device. If map-index settings also changed, it downloads a ZIP containing both JSON files.

The editor cannot overwrite server files. To install your changes, compare the downloaded files with the current originals and copy them into the maps folder yourself.

Making changes live

Saving here does not publish to the player website. Review your changed files, then use the existing repository review and deployment process to publish them. Generated previews and publishing are separate from this editor.
